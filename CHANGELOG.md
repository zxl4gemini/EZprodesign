# Changelog

## 0.1.0 — first public release (2026-10-21)

- Extracted a deliberately curated generic software version into a fresh
  independent Git repository, without private research Git history.
- Opened local CPU structure analysis, 3Dmol.js browser and public CC0
  ubiquitin (PDB 1UBQ) demonstration.
- Added a concise CLI `--summary` option and configurable loopback-only port.
- Added MIT project license; preserved upstream 3Dmol.js BSD-3-Clause notices.
- Added public-only regression tests, CI and scientific nonclaims.
- Excluded research datasets, model weights, candidate binders, HPC paths,
  credentials, original run outputs and active v16–v18 research work.
